# README.md
THE  GRADEBOOK  MANAGEMENT  SYSTEM  ASSIGNMENT

This project involves the development of a Gradebook Management System in Python.
The system was enhanced progressively through Sections A, B, and C, with each section building on the previous one to improve the management and organization of student records.

Section A: Scalar Objects and Loops
Features
- Captures the number of students.
- Accepts student names and grades.
- Validates grades to ensure they are between 0 and 100.
- Calculates the class total and class average.

Concepts i used
- Variables
- Input and output
- For loops
- While loops
- Conditional statements

Section B: Lists and Tuples
Features
- Records grades for Mathematics, English and Science.
- Stores student grades in a list.
- Stores each student record as a tuple.
- Calculates each student's average.
- Displays highest and lowest grades for each subject.
- Generates a student summary report.

Concepts i used
- Lists
- Tuples
- Loops
- Average calculations
- max() and min() Functions


Section C: Dictionaries
Features
- Replaces the list of tuples with a dictionary structure.
- Uses student names as dictionary keys.
- Stores subject grades using nested dictionaries.
- Adds a new student.
- Updates an existing student's grades.
- Removes a student from the system.
- Displays grades for a selected subject across all students.
- Searches for a student by name and displays their grades and average.

Concepts i used
- Dictionaries
- Nested Dictionaries
- Dictionary Search
- Dictionary Update
- Dictionary Delete Operations

Conclusion
The Gradebook Management System demonstrates the use of python data structures and control structures to manage student records efficiently.
The project evolved from basic grade processing in Section A to dictionary-based data management in Section C.
